# Planner DM 4.0 · Remasterización

- Se sustituyó la taxonomía extensa por cuatro nombres de visita de Excelencia Operativa.
- Se integra una CDD por período para cada uno de los 10 gerentes.
- El filtro principal usa solo el nombre de visita; PPK y administración quedan como apoyos visibles.
- Se añadió un mapa SVG interactivo por zona: seleccionar una tienda enfoca la agenda y la ruta.
- La guía de visitas se genera con Python a partir del radar de sistemas.
- Se añadió una limpieza segura: primero audita; únicamente un despacho manual con `apply=true` borra archivos aprobados.
