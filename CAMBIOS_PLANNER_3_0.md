# Archivos de corrección · Planner DM 3.0

## Cambios de alto impacto

- **Ciclo por tienda:** una visita cada 10 días; elimina la sobrecarga de eventos diarios.
- **Agenda realista:** lunes/martes administrativos con 1–2 tiendas; miércoles–domingo 1–3 tiendas; inicio 08:00 en tienda y regreso máximo 18:00.
- **Ruta simple:** una zona por día: Izcalli o Coacalco–Ecatepec.
- **Filtro campaña:** Fall 26 / Xmas 26.
- **Filtros de visita unificados:** Mejora continua, Sistema crítico, Seguimiento 10 días, Desarrollo y talento, CDD, Junta Regional, PPK, Administrativo/soporte.
- **PPK:** sólo informativo; no compite con una visita de mejora.
- **Espacio protegido:** bloque para lo inesperado sin desplazar el foco de la tienda.
- **Mary · Cosmopol:** prioridad de desarrollo, cobertura y actividades de desarrollo.
- **CMS:** añade Radar de Sistemas: síntesis auditable de `Tipo Visitas DM.csv` para Duty Roster/limpieza, UKG, inventario, efectivo, RSA, experiencia, bebidas y canales digitales.

## Archivos a subir

Mantén las mismas carpetas del repositorio al cargar el contenido:

- `index.html`
- `css/styles.css`
- `js/app.js`
- `data/agenda_base.js`
- `data/planner_data.json`
- `manifest.webmanifest`
- `sw.js`
- `CMS/Planner_DM_3_0_CMS.xlsx`

## Primer uso

1. Sube el contenido y abre la PWA.
2. Pulsa **Regenerar base** una vez.
3. Trabaja cada lunes el Tablero y el Radar de Sistemas.
4. Antes de salir de una tienda, registra en el CMS: una práctica, dueño, fecha y evidencia.
